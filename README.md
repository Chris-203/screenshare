# Screen Share

Personal page for showing my Windows desktop to someone live while we're on FaceTime.

- **Share (PC):** open the site in Chrome/Edge → *Share my screen* → pick a window → send the link.
- **Watch (iPhone / iPad / Mac):** open the link in Safari. No app or account needed.

Video goes directly between devices over WebRTC; the free PeerJS broker only handles the initial handshake.
Hosted on GitHub Pages.
