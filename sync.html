Watch Sync

Our own Teleparty: when one of us plays, pauses or skips, the other's video does the same. Each of us streams from our own account, so the picture is full quality with no lag.

Download Watch Sync (.zip)

Works in Chrome or Edge on Windows and Mac. Not on iPhone or iPad.

Install (once, about a minute)

  1. Download the zip above and unzip it. On a Mac, double-click it; on Windows, right-click → Extract All.
  2. Open chrome://extensions (or edge://extensions) in the address bar.
  3. Turn on Developer mode (top-right in Chrome, left side in Edge).
  4. Click Load unpacked and pick the unzipped watch-sync folder.
  5. Click the puzzle-piece icon in the toolbar and pin Watch Sync.

Keep the unzipped folder where it is; Chrome loads the extension from it. Chrome may show a "developer mode extensions" notice on startup. That's normal for extensions you install yourself.

Using it

  1. Both of you open the same title on the same service.
  2. One person clicks the Watch Sync icon → Start a party on this tab and sends the 6-letter code.
  3. The other clicks the icon on their tab, types the code → Join. You'll both see "Synced".
  4. Watch. Play, pause and skipping now happen for both of you. A little message tells you who did what.

If you're on different episodes, a popup offers to open whatever the other person is watching. If the video ever drifts, the joiner is quietly nudged back in line.
